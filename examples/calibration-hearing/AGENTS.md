# Hearing record — project entry
Public synthetic CAL-02 prototype. Read PURPOSE.md and PROTOCOL.md before changing the model. Run Python 3.11+ with `python -B -m unittest -v test_hearing` in this directory. No Forge runtime or network is required.
The single-authority model, identity labels, private history and public projection are a prototype, not production security. Never treat a caller-provided actor string as authenticated. Use only invented data. Do not add networking, actual personal data or public deployment without a separate decision.
Work within the protected outcomes in PURPOSE.md. Evaluate any proposed protocol change against old-client replay, correction and withdrawal, competing drafts, and the distinction between private history and public projection. Preserve failures and report limitations. No additional agent is required for this prototype; domain consent/privacy review and independent verification would be separate responsibilities before real use.
Current next work: design a persistent and authenticated server contract, with atomic compare-and-set and deliberate retention policy, only after scope and narrator consent decisions are made. Before that, independent verification of the in-memory state model can proceed. See PROTOCOL.md for deferred questions.

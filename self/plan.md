# Engineering Forge 自己適用計画（v0.7-dev）
人間の目的: 製品分類に限定されず、AIが個別の開発体制を考案する仕組みを、GitHub参照から利用できるようにする。
個人的な会話原文は公開版に移さない。保護要求と委任範囲を変更する際は明示的な承認を得る。
最小構成: 設計・実装担当と別コンテキストの独立評価担当。実効的な権限分離は未確認。人間は随時直接介入できる。
公開リポジトリへの登録は人間が許可済み。main の直接更新は今回の空リポジトリ初期登録に限定。今後の大きな変更は短命ブランチとレビュー、force push禁止、外部プロジェクト変更禁止。秘密情報を保存しない。
S0: 設計資産整理済み。S1: 主要設計資産の GitHub 登録、残りの移行、独立設計監査、Codex実機検証。S2: 最小の初期化機能。今回はリスクが限定的な読み取り専用previewのみ並行して実装。適用機能は独立監査と競合・権限検証後。S3: 変更管理・更新・適応。S4: 実案件の対照比較。
R06の方法間競合・相互作用が旧統合要求から明示されなくなった点は改訂候補として保留。48要求の本文は勝手に変更しない。
